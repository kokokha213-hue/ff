# Cosmic Synaptic — Frontend-only Hacker-style Prediction Demo

This ZIP contains a single `index.html` file which runs entirely in the browser. No server or Python is required.

How to use:
1. Create a new GitHub repository (public). 
2. Upload the files from this ZIP (you can upload the single index.html). 
3. In repo Settings -> Pages, set source to `main` branch and root (`/`).
4. Your site will be available at `https://<username>.github.io/<repo>/`.

Features:
- Next Prediction button
- Color (🔴/🟢/🟣), Big/Small, Number, Confidence%
- Local persistence via localStorage (AI_MEMORY)
- Hacker-style UI
